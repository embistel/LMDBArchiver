## 📐 CMake 구조 (`CMakeLists.txt`)

```cmake
project(LMDBArchiver VERSION 0.1.0 LANGUAGES C CXX)
set(CMAKE_CXX_STANDARD 17)        # REQUIRED ON, EXTENSIONS OFF
set(CMAKE_AUTOMOC ON)             # set(CMAKE_AUTORCC ON / AUTOUIC ON)
```

### LMDB 가져오기 (FetchContent)
```cmake
FetchContent_Declare(lmdb
    GIT_REPOSITORY https://github.com/LMDB/lmdb.git
    GIT_TAG LMDB_0.9.33
    GIT_SHALLOW TRUE
    SOURCE_SUBDIR libraries/liblmdb)
```
→ `lmdb_vendor` 정적 라이브러리 (`mdb.c`, `midl.c`). Win32: `_CRT_SECURE_NO_WARNINGS`, `Advapi32`.

### 타깃 요약
→ [[01·아키텍처 개요#빌드 타깃 (CMakeLists.txt)]]

### 컴파일 옵션 (MSVC)
- `/W4 /permissive- /utf-8` (core, GUI, CLI)
- GUI 추가: `QT_NO_CAST_FROM_ASCII`, `QT_NO_CAST_TO_ASCII`

### 설치 규칙
`GNUInstallDirs` 기준 `bin/`에 두 실행파일 설치 + `README.md`, `LICENSE`.

### 테스트
```cmake
include(CTest)
if(BUILD_TESTING)
    add_executable(lmdbarchiver_tests tests/archive_test.cpp)
    target_link_libraries(lmdbarchiver_tests PRIVATE lmdbarchiver_core Qt6::Test)
    add_test(NAME archive-core COMMAND lmdbarchiver_tests)
endif()
```

## 🚀 로컬 빌드 (PowerShell / MSVC)

```powershell
$env:QT_ROOT = 'F:\Qt\6.11.0\msvc2022_64'   # Visual Studio Developer PowerShell
cmake --preset qt-msvc-release
cmake --build --preset release
ctest --preset release
```

Qt 설치 경로만 `QT_ROOT`로 바꾸면 된다.

## 🤖 GitHub Actions (`.github/workflows/build.yml`)

`on: [push, pull_request]` — 두 개 잡.

### `windows` 잡 (`windows-2022`)
1. `actions/checkout@v4`
2. `jurplel/install-qt-action@v4` → Qt 6.8.x `win64_msvc2022_64` (캐시)
3. Configure: `Visual Studio 17 2022 -A x64 -DBUILD_TESTING=ON`
4. Build (`--config Release`) → Test (`ctest -C Release`)
5. **Package**: `scripts/build-msi.ps1` (windeployqt 경로 자동 추출)
6. `upload-artifact@v4`: `out/*.msi`, `out/*.zip`

### `unix` 매트릭스 (`ubuntu-latest`, `macos-14`)
1. checkout + Qt 6.8.x (캐시)
2. Configure: `Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON`
3. Build → Test (`ctest`)
4. (패키징 없음 — 코어/UI 검증용)

> [!note] CI 전략
> Windows는 코어+UI+MSI 패키지까지, Unix는 코어/UI 크로스플랫폼 빌드+테스트만. Win32 셸 통합은 컴파일만 확인(런타임은 Windows 전용).

## 🔁 호환성 원칙 (DEVELOPMENT.md)

- C++17 / Qt 6.2 공개 API 범위 유지
- Qt 패치 버전이나 **절대 경로**를 소스에 하드코딩하지 않음 (`QT_ROOT` 환경변수)
- Windows/MSVC가 주 타깃, 코어/UI는 Linux/macOS 빌드 가능
- 셸 통합은 `Q_OS_WIN`으로 격리
