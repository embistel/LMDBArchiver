# 08 · 패키징과 배포

> [!info] 위치
> `scripts/package.ps1` (휴대용 ZIP) · `scripts/build-msi.ps1` (MSI) · `installer/Product.wxs` (WiX 정의)

## 두 산출물

| 산출물 | 경로 | 용도 |
|---|---|---|
| **MSI** | `out/LMDBArchiver-<ver>-x64.msi` | 시스템 설치 (권장) |

## 📦 `scripts/package.ps1` — 휴대용 스테이징

`build-msi.ps1`이 먼저 이 스크립트를 호출해 공통 페이로드를 준비한다.

**매개변수:** `-BuildDirectory` (기본 `build/release`), `-QtBin` (기본 `$env:QT_ROOT\bin`)

**절차:**
1. 빌드 산출물(`LMDBArchiver.exe`, `LMDBArchiverCLI.exe`) 존재 확인
2. 스테이지 디렉터리(`out/LMDBArchiver-0.1.0-win64/`) 정리 후 생성
3. 복사: 두 실행파일 + `README.md` + `LICENSE` + `THIRD_PARTY_NOTICES.md` + `USER_GUIDE.ko.md` + `docs/images/`
4. 라이선스: LMDB(`_deps/lmdb-src/.../LICENSE` → `LICENSE-LMDB.txt`), Qt SDK `LICENSE` → `LICENSE-QT.txt` (있으면)
5. `windeployqt --release --no-translations --no-compiler-runtime` → Qt DLL/플러그인 수집
6. **MSVC 런타임** 수동 복사:
   - `$env:VCToolsRedistDir` 우선, 없으면 `vswhere`로 최신 VC143 폴더 탐색
   - `x64\Microsoft.VC143.CRT\*.dll` 복사
7. `Compress-Archive -CompressionLevel Optimal` → `out/LMDBArchiver-0.1.0-win64.zip`

> [!warning] 하드코딩된 버전
> `0.1.0`이 스크립트와 스테이지 이름에 고정되어 있다. 버전 올릴 때 `build-msi.ps1 -Version`과 함께 수동 갱신 필요.

## 🏗️ `scripts/build-msi.ps1` — MSI 생성

**매개변수:** `-BuildDirectory`, `-QtBin`, `-Version` (기본 `0.1.0`)

**절차:**
1. `package.ps1` 호출 (페이로드 스테이징)
2. **WiX 5.0.2** 로컬 설치:
   - `build/tools/wix/wix.exe`
   - 없으면 `dotnet tool install wix --tool-path ... --version 5.0.2`
   - 시스템 전역 설치 건드리지 않음
3. `wix extension add WixToolset.UI.wixext/5.0.2`
4. `wix build installer/Product.wxs`:
   - `-arch x64`
   - `-ext WixToolset.UI.wixext`
   - `-bindpath Payload=<stage>` (File 요소가 여기서 인용)
   - `-define Version=<ver>`
   - `-defaultcompressionlevel high`
   - 출력: `out/LMDBArchiver-<ver>-x64.msi`
5. `wix msi validate <output>` — 스키마/일관성 검사

## 📜 MSI 정의 (`installer/Product.wxs`)

→ [[06·Windows 셸 통합#MSI (installer/Product.wxs) — HKLM 등록]]에 레지스트라 항목 정리.

### 핵심 속성
- `Name="LMDB Archiver"`, `Manufacturer="embistel"`, `Scope="perMachine"`
- `Codepage="65001"` (UTF-8), `InstallerVersion="500"`, `Compressed="yes"`
- `UpgradeCode="EECAB4C2-AB2B-4A24-B1F0-2694FA78047F"` (고정)
- `MajorUpgrade` — 다운그레이드 시 에러 메시지
- 시작 메뉴 바로가기 (advertised shortcut)
- `WixUI_InstallDir` + `installer/license.rtf`

### 컴포넌트
| 컴포넌트 | 역할 |
|---|---|
| `MainExecutableComponent` | `LMDBArchiver.exe` + 시작메뉴 바로가기 |
| `CliExecutableComponent` | `LMDBArchiverCLI.exe` |
| `ShellIntegrationComponent` | HKLM 레지스트리 (파일 연결 + 메뉴) |
| `Files Include=!(bindpath.Payload)\**` | 나머지 페이로드 (Qt DLL 등), exe 2개 제외 |
