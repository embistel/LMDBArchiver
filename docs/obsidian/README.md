## 특징

- **이중 링크**: 노트 간 `[[위키링크]]` 로 양방향 참조
- **MOC 패턴**: 중앙 색인에서 방사형 탐색
- **콜아웃**: `> [!note]`, `> [!important]`, `> [!warning]` 으로 중요 정보 강조
- **프론트매터**: `tags`, `up`, `created`, `aliases` 로 메타데이터 관리
- **이미지**: `../images/*.png` 상대 경로 (docs/images/ 에 실제 파일 존재)

## 옵시디언 설정 팁

1. 설정 → 파일 및 링크:
   - **새 링크 형식**: 상대 경로가 아니어도 됨 (노트가 한 폴더에 있음)
   - **엄격한 줄 바꿈** 끄기 권장
2. 커뮤니티 플러그인 추천:
   - **Dataview** — 프론트매터 기반 표 자동 생성
   - **Graph View** (내장) — 노트 간 연결 시각화
3. 별칭(`aliases`)으로 `[[LMDB Archiver]]`, `[[LMDBArchiver]]`, `[[LMDB 아카이버]]` 모두 MOC로 연결
