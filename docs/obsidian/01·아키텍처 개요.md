```

│  ├─ MainWindow   메뉴·툴바·트리·상태표시줄                │
│  ├─ ArchiveModel QStandardItemModel (트리 빌드)           │

┌────────────────────────▼────────────────────────────────┐

┌────────────────────────▼────────────────────────────────┐
│  lmdb_vendor    LMDB 0.9.33 정적 라이브러리               │
│  └─ mdb.c · midl.c  (FetchContent로 GitHub에서 가져옴)    │

┌─────────────────────────────────────────────────────────┐
│  src/platform   Windows 전용 (Q_OS_WIN 격리)              │

└─────────────────────────────────────────────────────────┘
```

> [!important] 계층 분리 원칙
> `src/archive`는 **Qt Core와 LMDB에만** 의존한다. UI(Qt Widgets)가 없어도 빌드·테스트된다. 그래서 같은 코어를 GUI·CLI·향후 네임스페이스 확장이 모두 재사용한다.

## 📦 빌드 타깃 (CMakeLists.txt)

| 타깃 | 타입 | 설명 | 링크 |
|---|---|---|---|
| `lmdb_vendor` | STATIC | LMDB 0.9.33 (mdb.c + midl.c) | Threads, DL, Win32: Advapi32 |
| `lmdbarchiver_core` | STATIC | `src/archive/*` — 순수 코어 | Qt6::Core, lmdb_vendor |
| `LMDBArchiver` | WIN32 EXE | GUI 앱 (main.cpp + app/ + platform/) | core, Qt6::Widgets, Win32: Advapi32, Shell32 |
| `LMDBArchiverCLI` | CONSOLE EXE | CLI (`src/cli/main.cpp`) | core, Qt6::Core |
| `lmdbarchiver_tests` | TEST | `tests/archive_test.cpp` | core, Qt6::Test |

> MSVC 컴파일 플래그: `/W4 /permissive- /utf-8`. GUI는 추가로 `QT_NO_CAST_FROM_ASCII` / `QT_NO_CAST_TO_ASCII`.

## 🔄 대표 데이터 흐름

### 파일 추가 (Add)
```
사용자 드롭/선택
  └─ MainWindow::addLocalPaths
       └─ Archive::addPaths(paths, destination, &error, progress)
            ├─ 1. 파일 트리 순회 → pending 리스트 + 총 바이트 계산
            ├─ 2. ensureCapacity() — map size 2배 단위 확장
            ├─ 3. mdb_txn_begin (단일 쓰기 트랜잭션)
            │     for each pending:
            │       ├─ [디렉터리] 스킵 (Native 스키마는 디렉터리 미저장)
            │       └─ [파일] readAll → mdb_put(key=경로, value=원본바이트)
            └─ 4. mdb_txn_commit (실패 시 abort → 원자성 보장)
       └─ refresh() → ArchiveModel 업데이트
```

### 파일 추출 (Extract)
```
Archive::extract(paths, destination, &error, progress) [MDB_RDONLY]
  ├─ entries()로 총 바이트 사전 집계 (진행률 표시용)
  ├─ mdb_cursor_get(MDB_NEXT) 순회
  ├─ 경로 순회 방지: destinationRoot 하위인지 검증
  └─ 파일 → QSaveFile
       ├─ file.write(value.mv_data)  ← 원본 바이트 그대로
       └─ commit() (임시 파일 atomic rename)
```

## 🎯 설계 철학

### 1. 완전한 이식성
키는 UTF-8 경로, 값은 원본 파일 바이트. 헤더·매직·압축이 없어 LucioraEla 원 시스템과 모든 표준 LMDB 도구가 직접 읽고 쓸 수 있다. → [[02·아카이브 포맷 (Native)]]

### 2. 원자성 (Atomicity)
모든 쓰기 작업은 **단일 LMDB 트랜잭션**. 커밋 전 오류/취소 시 아카이브는 이전 상태 그대로. → [[03·Archive 코어 API#트랜잭션과 취소]]

### 3. 플랫폼 격리
Windows 셸 코드는 `Q_OS_WIN` 블록으로 격리, 다른 OS에서는 명확한 오류. 코어/UI는 크로스플랫폼.

### 5. 하위 호환성
포맷 변경 시 기존 판독기 유지 + `kFormatVersion` 상승. v1(레거시)은 계속 읽기 가능. → [[02·아카이브 포맷 v2#버전 호환성]]
